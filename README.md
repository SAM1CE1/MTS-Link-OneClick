# MTS Link OneClick — ссылка → MP4

**Вставь ссылку на запись МТС Линк, нажми «Скачать MP4» и получи видео показанных материалов со звуком — без веб-камер.**

Неофициальный open-source инструмент для Windows. Старается восстановить **слайды по таймкодам** и/или **отдельный поток демонстрации экрана**, совместив их со звуком выступающих. Не заменяет показанный контент видео с веб-камер и не создаёт «успешный» чёрный MP4, если материалы не обнаружены.

> **Статус: экспериментальная версия (v0.1.0).** Алгоритм проверен на синтетических тестах, но не гарантирует результат для каждой реальной записи МТС Линк. Сервис меняет формат данных; доступ к закрытым записям зависит от разрешений.

## Быстрый старт на Windows

1. Скачай исходники: **Code → Download ZIP** и распакуй архив в папку.
2. Установи [Python 3.10 или новее](https://www.python.org/downloads/windows/), если ещё не установлен. Во время установки выбери **Add Python to PATH**.
3. Запусти двойным щелчком `START_MTS_LINK.cmd`. При первом запуске скрипт при необходимости установит Pillow и FFmpeg-компонент через `pip`.
4. Вставь **ссылку на запись**, выбери папку и нажми **«Скачать MP4»**.
5. Нажми «Открыть результат». Проверь видео и звук в начале, середине и конце.

Примеры поддерживаемых адресов (вместо чисел — реальные ID):

```
https://my.mts-link.ru/12345678/87654321/record-new/1234567890
https://my.mts-link.ru/j/12345678/meeting-room/record-new/1234567890
https://my.mts-link.ru/j/12345678/meeting-room/record-new/1234567890/record-file/11223344
```

Папка результата по умолчанию: `Загрузки/MTS_Link_<ID>`. Основной файл: `PRESENTATION_OR_SCREEN_WITH_AUDIO_NO_WEBCAMS.mp4`.

## Что делает программа

- Получает метаданные **доступной** записи МТС Линк через HTTPS.
- Выбирает слайды из событий `presentation.update` и начального снимка состояния записи, получает их изображения и учитывает время переключений.
- Если запись содержит медиапоток, **явно обозначенный** `screensharing`, получает его видео и использует поверх слайдов в соответствующий промежуток времени.
- Читает доступные медиаисточники конференции, извлекает **только аудио** и сводит его по времени. Видео с веб-камер **не сохраняется и не вставляется** в результат.
- Создаёт MP4 (1280×720, 15 fps, H.264 + AAC), файл отчёта `MTS_RESULT_REPORT.txt` и предварительный просмотр слайдов `_assets/SLIDE_PREVIEW.jpg`.
- Повторно использует уже сохранённые ресурсы и аудиокэш при повторном запуске той же записи.

## Ограничения

- Встроенные **слайды — это статичные изображения**. Курсор, анимация, чат, виджеты и другие интерактивные элементы могут не сохраниться.
- Если демонстрация экрана **не представлена отдельным доступным видеопотоком**, программа не сможет воссоздать её движения из ничего.
- Алгоритм сводит аудиопотоки автоматически; на некоторых записях возможны рассинхрон, наложение голосов или пропуски.
- Закрытые записи могут требовать входа или права организатора. Инструмент **не обходит** эти ограничения и не реализует вход с cookie.
- Не предназначен для загрузки материалов, права на которые у тебя отсутствуют.
- Работа проверена на тестовых данных; полного тестирования на различных реальных записях ещё нет.

## Управление и ошибки

- **Остановить** — прекращает задачу. Уже полученные временные файлы остаются в папке `_assets`.
- Для повторной попытки вставь ту же ссылку: кэш будет использован повторно.
- Если что-то пошло не так, приложи текст ошибки и `MTS_RESULT_REPORT.txt` (без ссылок с секретными токенами).
- Если нет данных слайдов и отдельного `screensharing`, программа **завершится с ошибкой**, а не соберёт веб-камеры.

## Запуск из терминала

Для разработчиков доступен режим без GUI:

```powershell
python -m pip install -r requirements.txt
python mts_backend.py "https://my.mts-link.ru/12345678/87654321/record-new/1234567890"
```

Для тестов нужен FFmpeg и библиотека Pillow; на Windows можно использовать FFmpeg из `imageio-ffmpeg`:

```powershell
python -m unittest discover -s tests -v
```

## Как это устроено

`MTS_Link_OneClick.pyw` — интерфейс на Tkinter. `bootstrap.py` — запуск и установка необходимых зависимостей. `mts_backend.py` — чтение метаданных, загрузка слайдов, распознавание типов медиапотоков, сведение звука и сборка через FFmpeg. `tests/` — тесты на искусственных видео и слайдах.

**Приватность:** исходники открыты, данные обрабатываются локально; обращения выполняются к API и медиафайлам МТС Линк и к PyPI при первой установке зависимостей. Готовые видео и временные файлы сохраняются на твоём компьютере. Программа не требует вводить пароль или токен GitHub.

## Правовой статус и благодарности

Независимый проект, **не связан с МТС и не одобрен МТС Линк**. Название «МТС Линк» принадлежит правообладателю.
