# Изменения

## 0.1.0 — 2026-11-05

- Один GUI для различных ссылок записей МТС Линк.
- Восстановление статичных слайдов и явно помеченных потоков демонстрации экрана.
- Сведение аудио из медиафрагментов без вставки веб-камер в видео.
- Кэш ресурсов, отчёт обработки, предварительный просмотр изображений.
- Экспериментальная сборка; проверена на синтетическом тесте, не на широкой выборке реальных записей.
